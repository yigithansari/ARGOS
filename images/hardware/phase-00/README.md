# Phase 00 Hardware Evidence

This directory contains hardware photographs from ARGOS Phase 00 bench validation.

## Files

- `ARGOS_Phase00_Bench_Platform_Top_View.jpg` - Final overhead view of the integrated bench platform.
- `19-07-2026-power_module_front.jpeg` - Power Module V1 front view.
- `19-07-2026-power_module_back.jpeg` - Power Module V1 rear and wiring view.

The overhead photograph shows the complete bench setup, including the STM32 board, ESP32-C3, OLED, power module, motor drivers, motors and encoders, MPU6050, both VL53L0X sensors, wiring, and common power connections.

These files are retained as visual evidence for the Phase 00 exit baseline.
