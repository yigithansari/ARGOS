# ARGOS Chassis V1

This directory contains the first ARGOS chassis design created for Phase 01 mobile-platform development.

## Files

- `ARGOS_Chassis_V1.f3d` - Fusion 360 source design.
- `ARGOS_Chassis_V1.dwg` - DWG drawing/export for review and manufacturing preparation.

## Status

Chassis V1 design is complete and establishes the first mechanical baseline for active Phase 01 development. Fit, mounting positions, clearances, manufacturability, and subsystem placement shall be validated before fabrication or final assembly.

Future revisions should be stored in separate version directories to preserve design history.
