# ARGOS Wheel V5

This directory contains the laser-cut wheel manufacturing baseline used on the assembled mobile platform.

## Files

- `ARGOS_Wheel_Laser_Cut_V5.dxf` - DXF manufacturing file in millimetres.
- `ARGOS_Wheel_Laser_Cut_V5_Preview.png` - Layout and assembly preview.

## Manufacturing Notes

- Material thickness: 2.8 mm wood.
- Layout: eight wheel parts, four closed mould rings, and one three-hole bridge.
- Cutting area: 218 x 400 mm.
- Kerf compensation is not included.
- Verify the shaft bore and mould-release method on a sample before producing the full set.
